🪪 Profile Card
Página simples de perfil pessoal desenvolvida como exercício de prática em HTML e CSS.
🛠️ Tecnologias

HTML5
CSS3 (interno)

📚 Conceitos praticados

Flexbox para alinhamento e centralização
Border-radius e box-shadow
Efeito glassmorphism com backdrop-filter
Hover com transition suave
Background com imagem e background-size: cover

🚀 Como visualizar
Basta abrir o arquivo index.html no navegador.
